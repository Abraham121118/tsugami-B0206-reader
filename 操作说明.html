津上 B0206V 常规操作及面板按钮说明

整理自：S205A 客户培训资料 2024（同系列机型）/ 网络津上走心机教学视频 / FANUC 车床系统通用操作 —— 具体按键名称与位置请以本机实际面板为准

一、开机前的确认与开机

1. 通电前检查培训资料

1
机器额定电源电压 AC200V ±10%；初次通电前用相位旋转表确认 L1/L2/L3 (R·S·T) 相位顺序，相位接错会导致错误动作和人身事故。
2
确认各处螺栓、连接器、空压配管已拧紧。
3
确认外设（送料机、排屑机）配线配管正确；先取下运输固定具（红色）并妥善保管，移动机器前再装回。

2. 环境与油液培训资料

项目要求
环境温度5~40℃；稳定高精度加工建议维持 20℃ 左右
湿度75% 以下
导轨润滑油1.8 升，ISO VG68 同级
主轴冷却油8 升，ISO VG2 同级
空压源0.4MPa 以上，耗气约 40NL/min

3. 开机顺序

1
确认气压 0.4MPa 以上、油液正常。
2
打开机床总电源（主断路器）→ 按 NC 电源接通按钮，等待系统启动。
3
松开急停（红色蘑菇钮，向右旋转弹出）。
4
有报警先按复位 RESET；切换到手轮回零模式，将 X1/Z1（主轴侧）与 X2/Z2（副轴侧）各轴回参考点，观察机械坐标归零。
5
主轴低速试转（MDI 方式输入 S100 M03;）确认无异常后开始加工准备。
⚠️ 机器长期停机后首件务必用单段+低倍率空跑，确认程序无误再正常加工。

二、面板认识FANUC 通用

1. 模式选择旋钮（左上角）

模式用途
EDIT 编辑编写、修改程序（PROG 键进入程序画面）
MEM / AUTO 自动运行存储器里的程序（循环启动）
MDI手动输入单段指令执行（换刀、试转主轴、改参数时用）
HND 手轮手摇脉冲发生器移轴（对刀、找原点、导套更换）
JOG 手动按住轴方向键连续移动（配手动快速）
REF 回零开机后各轴回参考点

2. 键盘区常用键

按键功能
POS位置画面（实际位置 / 机械坐标 / 剩余移动量）
PROG程序画面（编辑/目录/MDI 输入）；津上机用「显示」键可在主轴/副轴程序目录间切换
OFS/SET刀补、工件坐标系设定画面（对刀后输刀补；I/O 通道也在这里改）
SYSTEM参数画面（零点 1815、K 参数 PMC 维护都在这）
MESSAGE报警信息、操作履历
CSTM/GRPH定制画面 / 图形模拟
RESET复位：消除报警、中止程序运行、退回输入状态
INPUT INSERT DELETE ALTER CAN EOB输入 / 插入 / 删除 / 替换 / 取消 / 换行(分号)

3. 操作区按键与旋钮

按键功能
循环启动（绿色）自动/MDI 模式下开始执行程序
进给保持（红色）暂停进给（主轴不停），再按循环启动继续
急停（红蘑菇）立即停止一切动作（断电式）；换夹头等作业前建议按下
进给倍率旋钮0~120% 调整进给速度（空跑时调低）
主轴倍率旋钮50~120% 调整主轴转速
快速倍率G00 快移速度挡位
单段每按一次循环启动只走一段，试加工必用
空运行 DRN按设定速度快速跑程序（不切削，验证轨迹用）
跳过 /打开后程序里 / 开头的段被跳过（津上接料、等待码等斜杠段）
选择停止打开后 M01 生效（津上程序每段末尾基本都有 M01）

4. 津上操作面板（导套/夹头画面）培训资料

1
按定制键显示主菜单画面，用软键（屏幕下方对应按键）选择项目。
2
导套设置画面软键：无导套 / 夹头更换 / 刹车关闭 / 旋转(旋转导套) / 电导套，用软键【开】把「旋转」设为开，则「夹头更换」也联动变开。
3
画面显示三组坐标：实际位置 / 机械坐标 / 剩余移动量，下方有刀具偏置数、热位补偿等项目。
4
主轴 NC / 副轴 NC：本机是双系统（主轴侧+副轴侧各自有程序），拷程序、看目录时先确认当前在哪个 NC 模式。

三、常用操作流程

1. 夹头更换培训资料

1
按下急停再操作。
2
安装：把适配器的主轴销与适配器键槽对正装入；装上夹头、锁紧螺帽。主轴螺帽锁紧后才可调夹紧力。
3
夹紧力调试：用开闭棒插入气缸孔口手动拉紧，感到阻力后锁紧调节螺母端面螺丝，再用开闭棒确认夹紧力。左手不动右手顺时针松调节螺母端面螺丝；右手不动左手顺时针调大夹紧力。
4
副轴夹头安装与夹紧力调试与主轴相同。
5
面板切换：按操作键进入导套模式更换界面 → 把「旋转导套」设为开 →「夹头更换」随之变开 → 机械更换完成后把「夹头更换」选项关闭（此时会报 Z1 负向超程，手轮摇回加工范围内按复位即可）。

2. 无导套 ⇄ 旋转导套切换网络教程

1
手轮按 J1 将导套推至后退极限位置直至报警 → 按复位消除报警。
2
切换页面至「偏置」→ 按操作键 → 打开「更换导头」功能。
3
参数设置：关闭「无导套」、打开「更换导套」→ 再按复位。
4
手轮按 Z1 控制导套后退，看设备指示箭头到标记位置停止 → 执行「安全复位」。
5
机械更换完成后：手轮按 J1 将夹头放入导套并顺时针拧紧 → 关闭「更换夹头」、打开「旋转导头」→ 切回正常操作页面。

3. 对刀与刀补FANUC 通用

1
手轮模式，用要对的刀试切外圆/端面（或对空定位）。
2
量出尺寸，按OFS/SET 进入刀补画面，找到对应刀号。
3
X 向：输入测量直径（直径值）+ 测量 软键；Z 向同理。
4
加工中微调尺寸改磨损列即可（津上程序大量用 T0606 这类刀号+刀补号形式）。

4. 程序创建与编辑网络教程

1
模式旋到 EDIT，按PROG 键。
2
输入 O + 4 位数字（如 O2310）按 INSERT 创建程序名。程序名后不要加分号 EOB，否则报格式错误。
3
逐段输入程序，每段结尾按 EOB + INSERT。
4
主轴程序、副轴程序是两个独立程序，分别在主轴 NC / 副轴 NC 下建立。

5. 程序拷贝（U 盘 / CF 卡）培训资料

1
按OFS/SET 设定键 → 切到 MDI 手动模式 → 光标移至 I/O 通道，输入通道号：U 盘 = 17，CF 卡 = 04。
2
按SYSTEM 参数键 → 软键黑色 + 键翻页找「所有 I/O」。
3
按PROG 程序键进入目录 → 按绿色操作键进入读取任务栏。
4
选择：F 读取=从 U 盘读入；N 读取=从 CF 卡读入；输出=机内程序拷到 U 盘/CF 卡。
5
F 名称设定 U 盘里的文件号，P 设定设定拷入机内的程序名 → 按执行。
⚠️ 拷程序前确认当前处于主轴 NC还是副轴 NC模式——处于哪个模式就拷入哪一侧的程序！

6. 试加工与自动加工

1
模式旋到 MEM/AUTO，PROG 键选中程序（津上程序 O 号为主轴程序，副轴程序由 /M9xxxx 呼叫）。
2
首件：打开单段、进给倍率调低、打开选择停止（让 M01 生效），按循环启动逐步确认。
3
空跑验证：打开空运行 DRN（不装料）快跑程序查轨迹和报警。
4
确认无误后关单段、倍率归位，正常加工。津上程序每个工序段末尾都有 M01，配合选择停止可逐段检查。

7. 报警处理

报警类型处理
一般报警排除原因后按 RESET 复位
OT 超程报警手轮往反方向摇出超程位置再复位；注意培训资料提示：刀尖朝向负方向侧可能造成 OT 报警（G02/G03 编程时刀尖方向要符合）
#3000 宏报警宏程序里人为设定的报警（如 M94 切料头的 T17_POS ERROR=切断刀不在挡料位置），按报警提示处理对应问题
急停报警旋出急停按钮后按复位

四、常用参数网络教程培训资料

参数说明
K 参数（PMC 维护）功能开关，取值只有 0（未开通）/1（已开通）。路径：参数页面 → 向右扩展 → 再扩展 → PMC 维护 → 向右扩展即见 K 参数。命名如 K3.0＝K3 行第 0 列、K9.6 通常为分度参数。培训资料里 G500 侧面孔倒角要求 K99#3=1 功能才有效——这列参数动之前先记下原值！
1815 号参数（APZ）零点丢失后重设：手轮把轴摇到机床出厂缺口标记 → MDI 方式参数写入开关打 1 → 参数画面搜 1815 → 该轴 APZ 改 1 → 提示关机重启 → 看机械坐标确认 → 参数开关打回 0 → 复位。
I/O 通道U 盘 = 17，CF 卡 = 04（程序拷贝用）
写参数参数画面里改为 1 才能改参数，改完务必改回 0
