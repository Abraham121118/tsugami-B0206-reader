# 走心机程序解读器（津上 B0206V）

**在线使用（手机、电脑都能开）：** https://abraham121118.github.io/tsugami-B0206-reader/

也可以把仓库整个下载下来，双击 `index.html` 打开 —— **无需安装、可离线使用**（照片 OCR 功能需要联网）。

## 功能

1. **逐行解读**：粘贴 / 拖入程序文件（.nc/.txt），每一行拆出 G/M/T/S/F 代码和坐标，
   逐条解释含义并拼成一句人话（如 `G99 G0 X22.0 Z0.0` → 「快速定位到 (X 22.0（直径）, Z 0.0)；每转进给」）。
   支持宏程序（`#` 变量、IF/GOTO、WHILE）、块跳过 `/`、循环续行识别（G90/G92/G75 的 X-only 行）。
2. **工序分段**：自动按 挡料 / 平端面 / 切断 / 副轴接料 / 拉料 / 极坐标 / C轴侧面加工 / 攻丝 / 换刀 分段并加说明。
3. **代码统计**：程序用到的所有代码、次数、含义；本程序用到的刀具清单。
4. **代码字典**：内置 100+ 条 G/M 码（津上专用 + FANUC 标准）。含义与你的机器不符？
   直接在表格里改，保存在本机浏览器（localStorage），也可导出/导入 JSON 分享给同事。
5. **公式速查**：螺纹底径、挡料长度、钻孔/攻丝深度、振动频率等车间常用公式。
6. **照片 OCR**：拍机器屏幕照片 → 识别成文字 → 修改后解读。
   ⚠️ 屏幕反光、0/O 易混，识别结果务必核对；最可靠的是直接拷程序文件。

另有 **`操作说明.html`**：津上 B0206V 常规操作及面板按钮说明（开机检查、面板按键、夹头更换、导套切换、对刀、程序拷贝、报警处理、常用参数、本机规格），从 index.html 右上角链接进入，可单独打印。

## 用法小贴士

- **在线版**：打开上面的网址即用，手机上用尤其方便，可以配合「照片 OCR」拍机器屏幕。
- **改代码字典**：改完存在你自己浏览器的 localStorage 里，**换浏览器/清缓存会丢**，
  重要改动请用「导出 JSON」备份，也可以发给同事导入。
- **离线版**：下载仓库后双击 `index.html`，字典存在本机，与在线版互不影响。

## 说明与免责

- 代码含义按津上同系列机型的培训/使用资料、网络教学视频与 FANUC 标准整理，页面内逐条标注了来源。
- 津上专用 M 码**因机型配置而异**（如 B0205-Ⅲ 与 S205A 的副轴程序呼叫码就不同），
  个别码请对照**本机说明书**在「代码字典」页校准。
- 本工具只做解读，不修改程序；程序上线前请用空走/单段验证。
